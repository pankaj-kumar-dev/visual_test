# Cypress Visual Test Builder

A node-based, drag-and-drop editor for building Cypress E2E tests visually — no code required.

Build a test as a graph of action nodes. The tool generates production-grade Cypress code and can parse that code back into the graph (fully reversible).

## Features

- Drag-and-drop action nodes: Visit, Click, Type, Assert
- Live Cypress code generation
- Import/Export flow as JSON
- Import existing Cypress code back into the editor
- One-click example flow (login flow)

## Setup

Requirements: Node.js 18+

```bash
git clone <repo-url>
cd visual_test/frontend
npm install
npm run dev
```

Open http://localhost:5173 — the app loads instantly.

## Usage

1. Drag an action from the **Actions** palette onto the canvas
2. Click a node to edit its parameters in the **Config** panel
3. The **Cypress code** panel updates live
4. Click **Copy** to copy the code, or **Export JSON** to save the flow
5. Click **Example** in the canvas header to load a ready-made login flow

### Example flow (login)

The built-in login flow produces:

```js
// Generated by Cypress Visual Test Builder
// Flow: Login Flow
// baseUrl: https://your-app.example.com

describe("Login Flow", () => {
  it("should complete the flow", () => {
    cy.visit('/login');
    cy.get('[data-cy="username"]').clear().type('admin');
    cy.get('[data-cy="password"]').clear().type('password123');
    cy.get('[data-cy="login-btn"]').click();
    cy.get('[data-cy="dashboard-heading"]').should('be.visible');
    cy.get('.welcome-banner').should('contain', 'Welcome');
  });
});
```

Load it: click **Example** in the canvas header, or import `frontend/examples/login-flow.json` via the **Import JSON** button.

## Architecture

```
frontend/src/
├── core/                    # Zero React. Pure JS logic.
│   ├── model/               # nodeSchema, edgeSchema, flowSchema
│   ├── state/               # useFlowStore (zustand)
│   ├── transformer/         # graphToLinear ↔ linearToGraph
│   ├── codegen/             # Flow JSON → Cypress code
│   └── parser/              # Cypress code → Flow JSON
├── features/
│   ├── palette/             # Draggable action templates
│   ├── canvas/              # Sortable node chain
│   ├── config/              # Per-node parameter editor
│   └── codegen/             # Code panel (generate + import/export)
├── app/App.jsx              # DndContext + layout
└── utils/id.js              # crypto.randomUUID wrapper
```

**Three mandatory transformations (all verified with round-trip tests):**

```
UI  ←→  Flow JSON  →  Cypress code
               ↑
        Cypress code  (parser)
```

**Data model:**

```
Flow   = { version, name, baseUrl, rootNodeId, nodes: Record<id,Node>, edges: Record<id,Edge> }
Node   = { id, type, params, position }
Edge   = { id, from: nodeId, to: nodeId, condition: 'success' }
```

MVP uses a single linear chain. The graph shape is already correct for adding branching/loops later via new edge types — no refactor needed.

## Tech stack

- @dnd-kit/core, @dnd-kit/sortable — drag and drop
- zustand — state management
- No other runtime dependencies
