# INSPIRATION — ISI GLOBAL
> isiglobal.com — International retail experience design agency
> Extract: sequential methodology presentation, numbered service cards, gallery-forward portfolio, light/dark toggle patterns

---

## WHAT ISI GLOBAL DOES DIFFERENTLY

ISI turns their process into the navigation. The five-phase methodology (Define → Design → Digital → Develop → Deliver) is both the service offering AND the information architecture. Study this for how to make a process feel like a product.

---

## SPACING PHILOSOPHY

**Observation:** Large image tiles carry weight; whitespace absorbs it.

- Project gallery uses generous gutters — images can be large without crowding
- Card sections breathe between each phase — the pause between cards signals distinct steps
- Negative space is proportional to content complexity: dense cards get more breathing room

**Extract:** When image content is primary, whitespace is a compression valve — increase it proportionally as image weight increases. Never pack large images together.

---

## TYPOGRAPHY RHYTHM

**Observation:** Refined, minimal type that steps back for imagery.

- Light/dark mode toggle implies neutral palette designed to work in both — no color-dependent hierarchy
- Numbered headings (01–05) do the hierarchy work — type size can stay restrained
- High contrast maintained across both modes — accessibility is structural, not afterthought

**Extract:** Sequential numbering (01, 02, 03...) is an underused typographic tool. It creates hierarchy, communicates process, and guides scanning — without increasing font size or weight.

---

## INTERACTION DENSITY

**Observation:** Expand/collapse cards for services — progressive disclosure on a structured list.

- Numbered service cards collapsed by default — headline visible, detail hidden
- User chooses depth — skim or read
- Hover states on project tiles — reveal project info without leaving the grid
- Light/dark toggle — user controls the visual register

**Extract:** For service-heavy pages, expand/collapse beats long scroll. It respects user intent: those who want detail get it; those scanning get overview. Collapse state is the default.

---

## INFORMATION HIERARCHY

**Observation:** Process as navigation — methodology names ARE the section headers.

- Define / Design / Digital / Develop / Deliver — alliterative, memorable, scannable
- Each phase card contains sub-services, not just descriptions
- Portfolio grid follows — work is proof of process, not separate from it

**Extract:** If your product/service has a clear process, make that process the organizing structure of the page. It doubles as navigation AND methodology credibility.

---

## EMOTIONAL TONE

**Observation:** Visionary storytelling without vagueness — grounded in retail specificity.

- "Shaping the future of retail" — big claim, but anchored by specific services
- "Authentic engagement" — differentiator language, not generic agency-speak
- Portfolio imagery shows physical retail spaces — tangibility counters abstraction

**Extract:** Bold positioning language works when paired with concrete specifics. "Shaping the future of X" requires immediate visual proof of what that looks like in practice.

---

## TRUST PATTERNS

**Observation:** Trust through demonstrated scope and global footprint.

- Large project imagery communicates execution quality before words do
- International client/project spread signals scale
- FAQ section addresses objections directly — shows agency confidence

**Extract:** For design/agency sites: quality of imagery IS the trust signal. A mediocre project grid destroys credibility faster than any missing testimonial.

---

## MOTION PHILOSOPHY

**Observation:** Hero video/image at top — motion concentrated at entry, not throughout.

- Motion budget spent on hero — first impression gets the dynamism
- Rest of page is static or subtle hover states
- Card expand/collapse: likely simple height transition, not animated spectacle

**Extract:** Concentrate motion at the entry point (hero). Diminishing returns after that — users are reading, not watching. Motion mid-scroll competes with content.

---

## WHAT NOT TO EXTRACT

- The 5-D alliterative framework — works for their brand, forced if invented for another
- Hero video at top — expensive to produce; don't placeholder with low-quality video
- Retail-specific visual language — project imagery only works when project quality is genuinely high
- Light/dark toggle — only add if you'll genuinely maintain both modes to high standard
