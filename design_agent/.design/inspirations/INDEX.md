## BY PROBLEM TYPE

**"My UI feels cluttered"**
→ Study: Linear (density management), Vercel (chrome minimalism), Lumin PDF (inter-section breathing room)

**"My dashboard has no hierarchy"**
→ Study: Stripe Dashboard (metric cards, reading grammar)

**"My product feels generic / bland"**
→ Study: Craft (warmth through micro-detail), Ingamana (personality through copy precision)

**"My portfolio / showcase page has no rhythm"**
→ Study: Ingamana (card grid as primary navigation), ISI Global (gallery + expand/collapse services)

**"My enterprise landing page feels weak or cluttered"**
→ Study: Lumin PDF (section order mirrors sales motion, trust hierarchy), Futureform (industry segmentation at nav level)

**"My B2B product feels generic / unconvincing"**
→ Study: Arcturis Data (noun-based tagline, restraint = precision), Futureform (industry-insider copy tone)

**"My product marketing feels cold or tech-bro"**
→ Study: Daylight Computer (outcome photography, aspiration + conviction)

**"I don't know how to present a complex service process"**
→ Study: ISI Global (methodology as navigation structure)

**"My empty states are bad"**
→ Study: Notion (empty as invitation), Stripe (empty as instruction)

**"My dark mode looks like an afterthought"**
→ Study: Vercel (first-class dark), Craft (warm dark)

**"My editor/content area feels like a tool, not a product"**
→ Study: Craft (editorial polish), Notion (chrome recedes)

**"Users don't trust our data"**
→ Study: Stripe (precision signals trust)

**"Developers say the product feels slow"**
→ Study: Vercel + Linear (minimal animation, snappy transitions)

## EXTRACTION PROTOCOL

For each inspiration, extract ONLY:
1. A spatial principle (spacing philosophy)
2. A typographic principle (rhythm, hierarchy)
3. An interaction principle (density, discovery, feedback)
4. A trust signal (what builds confidence)
5. An anti-pattern warning (what not to copy)

Never copy:
- Specific colors (those are brand, not principle)
- Specific icon choices (those are brand)
- Specific layout dimensions (context-dependent)
- Anything you'd need to license or reverse-engineer

## ADDING NEW INSPIRATIONS

When adding a new inspiration file, follow the template:
1. Product name + URL + one-line purpose
2. Why it matters (what unique problem it solves)
3. 5-7 extractions following the categories above
4. "What NOT to extract" section
5. Add to this INDEX.md

Anti-quality sources to avoid:
- Dribbble shots (no real product constraints)
- Awwwards winners (optimized for judges, not users)
- Portfolio redesign concepts (never shipped or tested)
- Products built primarily for visual wow factor

Quality sources:
- Mature shipped products with large user bases
- Products with strong design culture and public team
- Products that have measurably solved hard UX problems
- Products your target users actually use and trust
